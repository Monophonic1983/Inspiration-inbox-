# App Store 商店页：简体中文

**名称：** Inspiration Inbox（灵感收件箱）
**副标题：** 说出想法，得到整洁笔记

**宣传文本：** 按一下，说一句，放下手机之前，一条整理好的笔记就在收件箱里了。

**描述**
灵感收件箱是记录想法最快的方式。按下操作按钮，说出你的想法，它会变成一条干净、有结构的笔记：标题、整理后的文字、类型、标签和待办事项。

• 一键录音：操作按钮、控制中心、锁定屏幕都可以
• 中英文实时转写，离线也能用
• AI 只做编辑，不做创作：只整理你说的话，绝不添加内容
• 你的原话总是最先保存，一键即可查看
• 默认保护隐私：语音识别和 AI 都在 iPhone 上运行。云端为可选项，开启前会先征求你的同意
• 置顶、归档、搜索，并可分享为 Markdown 或纯文本
• 通过你的私人 iCloud 同步

没有文件夹，无需设置，只管记录。

**关键词：** 语音笔记,灵感,听写,记录,日记,待办,操作按钮,转写,备忘,收件箱
